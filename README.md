Number Guessing Game

Bu proje, Python öğrenme sürecimin 4. gününde geliştirdiğim basit bir **Sayı Tahmin Oyunu**dur.

Nasıl Çalışıyor?

Program 1 ile 100 arasında rastgele bir sayı oluşturur.

Kullanıcıdan tahmin alır ve:

 Tahmin gizli sayıdan küçükse → **Daha büyük bir sayı söyleyin**
 Tahmin gizli sayıdan büyükse → **Daha küçük bir sayı söyleyin**
 Tahmin doğruysa → **Tebrikler!**
 1-100 dışında bir sayı girilirse → Kullanıcıdan geçerli bir sayı ister.

Program ayrıca kullanıcının kaç tahminde doğru cevabı bulduğunu gösterir.
